# Smart Chain AI – Late Delivery Risk Prediction

## About the Project
Smart Chain AI is a machine learning-based dashboard for analyzing delivery performance, predicting late-delivery risks, and presenting useful business insights through interactive charts.

## Features
- Displays total orders and late-delivery statistics.
- Shows high-risk delivery predictions.
- Analyzes delivery performance by shipping mode.
- Compares late-delivery rates across regions.
- Displays sales across different markets.
- Provides business insights and recommendations.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Machine Learning

## How to Run
1. Download or clone this repository.
2. Install the required packages:
   `pip install -r requirements.txt`
3. Start the application:
   `streamlit run app.py`

## Project Objective
To analyze delivery data, identify high-risk orders, and support better logistics decisions through data-driven insights.
